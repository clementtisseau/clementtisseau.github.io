# AGENTS.md

## Purpose

This repository contains a minimal personal website for essays, notes, and blog posts.

## Principles

- Keep the site minimal.
- Prefer plain HTML and CSS.
- Do not introduce frameworks, build steps, package managers, or JavaScript unless explicitly requested.
- Preserve the visual style: white background, black text, blue links, serif typography.
- Favor simple structure over abstraction.

## Repository structure

- `index.html` — homepage
- `posts/` — individual posts
- `README.md` — short human-facing repo notes

## Editing guidelines

- Keep changes small and easy to understand.
- Do not redesign the site unless asked.
- Do not add tracking, analytics, cookie banners, or third-party UI libraries.
- Maintain good readability and a restrained layout.
- Keep the HTML hand-editable.

## Posts

When adding a new post:
1. Create a new HTML file in `posts/`
2. Add the post link to the `Thoughts` section in `index.html`
3. Keep naming simple and descriptive

## Styling

- Background: white
- Text: black
- Links: default blue style
- Typography: classic serif feel, preferably Computer Modern / Latin Modern style
- Overall aesthetic: text-first, quiet, and minimal

## When making changes

Before making bigger edits, prefer:
- improving existing HTML/CSS
- reducing complexity
- preserving the current tone of the site
