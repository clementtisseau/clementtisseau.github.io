# Personal website

A minimal personal website for short essays, blog posts, and notes.

## Structure

* `index.html` — homepage
* `posts/` — individual posts

## Editing

To update the homepage, edit `index.html`.

To add a new post:

1. Create a new HTML file in `posts/`
2. Add a link to it in the `Thoughts` section on the homepage
3. Commit and push

## Publishing

This site is hosted with GitHub Pages.

If the repository is named `yourusername.github.io`, the site is available at:

`https://yourusername.github.io`

## Design

The site is intentionally minimal:

* white background
* black text
* blue links
* serif typography
* no tracking
* no cookies

## Notes

This repository is meant to stay simple. The goal is to make publishing easy and maintenance minimal.
